## 🚀 Quick Start

```bash
# Install dependencies
bun install

# Run tests
bun test

# Run tests with coverage
bun run test:coverage

# Type check
bun run typecheck

# Lint
bun run lint

# Build
bun run build
```

## 📋 Before Submitting

1. ✅ All tests pass (`bun test`)
2. ✅ Code is formatted (`bun run format`)
3. ✅ No lint errors (`bun run lint`)
4. ✅ TypeScript compiles (`bun run typecheck`)
5. ✅ Follow [Conventional Commits](https://www.conventionalcommits.org/)
