# Examples

Welcome to the QuickModel examples! These practical examples demonstrate real-world usage patterns and best practices.

## Available Examples

### [Basic Usage](/en/examples/basic)

Learn the fundamentals of QuickModel with simple, straightforward examples covering:

- Creating your first model
- Property transformations
- Serialization and deserialization
- Working with arrays

### [API Models](/en/examples/api-models)

See how to integrate QuickModel with REST APIs:

- Fetching and transforming API responses
- Sending data to APIs
- Handling API date formats
- Working with pagination

### [Complex Types](/en/examples/complex-types)

Explore advanced type transformations:

- Nested models and deep nesting
- Collections (Set, Map)
- Binary data (ArrayBuffer, TypedArrays)
- Custom transformers
- Polymorphic models

## Example Structure

Each example follows this structure:

1. **Problem** - The challenge you're trying to solve
2. **Solution** - How QuickModel solves it
3. **Code** - Complete, runnable code
4. **Explanation** - Step-by-step breakdown
5. **Best Practices** - Tips and recommendations

## Running Examples

All examples are TypeScript and can be run with:

```bash
# Using Bun
bun run example.ts

# Using ts-node
npx ts-node example.ts

# Using tsx
npx tsx example.ts
```
