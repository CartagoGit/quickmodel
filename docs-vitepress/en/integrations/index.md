# Integrations

QuickModel integrates seamlessly with the most popular frameworks and libraries in the TypeScript/JavaScript ecosystem.

## Frontend Frameworks

### [Angular](/en/integrations/angular-integration)

Integration with Angular using services, HTTP interceptors and reactive forms.

### [React / Next.js](/en/integrations/react-integration)

Models with React hooks, Server Components and automatic transformation management.

### [Svelte 5 / SvelteKit](/en/integrations/svelte-integration)

Integration with Svelte 5's reactivity system and SvelteKit routes.

### [Vue 3 / Nuxt](/en/integrations/vue-integration)

Reactive composables, Pinia stores and server routes with Nuxt.

## Backend

### [Express / Fastify / Hono](/en/integrations/backend-integration)

DTO validation and transformation in REST APIs with the most popular Node.js frameworks.

### [NestJS](/en/integrations/nestjs-integration)

Integration with NestJS module system, validation pipes and guards.

### [tRPC](/en/integrations/trpc-integration)

End-to-end type safety with tRPC using QuickModel as the serialization layer.

### [GraphQL / Apollo Server](/en/integrations/graphql-integration)

GraphQL resolvers with automatic transformation of complex types.

## ORM & Databases

### [Prisma ORM](/en/integrations/prisma-integration)

Mapping between Prisma models and QModel with automatic transformations.

### [TypeORM](/en/integrations/typeorm-integration)

TypeORM entities as QModels with support for relations and inheritance.

### [Mongoose](/en/integrations/mongoose-integration)

Mongoose schemas with serialization of complex types (Map, Set, Date).

## State Management & Forms

### [Redux Toolkit (RTK)](/en/integrations/redux-toolkit-integration)

Redux slices with QuickModel in reducers, thunks and RTK Query.

### [Zustand](/en/integrations/zustand-integration)

Zustand stores with typed models and automatic persistence.

### [React Hook Form](/en/integrations/react-hook-form-integration)

Form validation with `@QRule` integrated into React Hook Form.

### [Formik](/en/integrations/formik-integration)

Using QuickModel as a validator and data transformer in Formik forms.

## Testing & Tooling

### [MSW (Mock Service Worker)](/en/integrations/msw-integration)

HTTP request interception in tests with realistic models generated by QuickModel.

### [Vitest Custom Matchers](/en/integrations/vitest-matchers)

Vitest-specific matchers for validating QModel instances in tests.

### [TanStack Query](/en/integrations/tanstack-query-integration)

Queries and mutations with automatic API response transformation.

### [OpenAPI / Swagger](/en/integrations/openapi-integration)

OpenAPI schema generation from QuickModel models.

## Other Integrations

### [Mobile (React Native / Capacitor)](/en/integrations/mobile-integration)

Using QuickModel in mobile applications with React Native and Capacitor.

### [Storage & Persistence](/en/integrations/storage-integration)

Persistence in localStorage, sessionStorage and IndexedDB with automatic serialization.

### [Electron IPC](/en/integrations/electron-integration)

Inter-process communication in Electron using QuickModel for safe serialization.
